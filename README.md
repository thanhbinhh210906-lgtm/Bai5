BIT240043 - Ứng dụng Quản lý Khóa Học (CourseManager)

- MSSV: BIT240043
- API Endpoint: https://6ad38e5759dd78397bbbdaa1.mockapi.io

Chức năng chính
- Xem danh sách khóa học, tìm kiếm, lọc theo danh mục.
- Xem chi tiết, phát video trailer.
- Thêm, sửa, xóa khóa học.
- Quản lý danh mục (ràng buộc không xóa danh mục đang có khóa học).

Hướng dẫn cài đặt và chạy
Yêu cầu môi trường:
- Đã cài đặt **Node.js** (khuyên dùng phiên bản LTS).
- Đã cài đặt ứng dụng **Expo Go** trên điện thoại (nếu muốn chạy trên Mobile).

### Các bước chạy:

Bước 1: Cài đặt các thư viện phụ thuộc (Dependencies)
Mở Terminal/CMD tại thư mục gốc của project và chạy lệnh:
npm install

Bước 2: Khởi chạy dự án
Chạy lệnh npx expo start sau để khởi động Metro Bundler

Bước 3: Xem giao diện ứng dụng
Trên Web: Nhấn phím w trong Terminal để tự động mở trên trình duyệt (http://localhost:8081).
Trên Mobile: Mở ứng dụng Expo Go, chọn "Scan QR Code" và quét mã QR hiển thị trên Terminal (Yêu cầu điện thoại và máy tính kết nối cùng mạng Wi-Fi).
